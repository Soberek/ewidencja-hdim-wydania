# Ewidencja HDiM — wydania

Instalatory i plik aktualizacji (`latest.json`) aplikacji **Ewidencja HDiM** — ewidencji kontroli Higieny Dzieci i Młodzieży w Państwowej Inspekcji Sanitarnej.

To repozytorium nie zawiera kodu źródłowego ani żadnych danych. Służy wyłącznie do publikowania podpisanych instalatorów, z których zainstalowana aplikacja pobiera aktualizacje.

**Instalacja:** pobierz plik `Ewidencja-HDiM_…_x64-setup.exe` z [najnowszego wydania](../../releases/latest) i uruchom (bez uprawnień administratora). Kolejne wersje aplikacja wykryje sama.
